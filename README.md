# Dr. Jorge Luiz Gervásio — Psiquiatra

Landing page institucional criada a partir do layout original de Chimara Emília, adaptada para o Dr. Jorge Luiz Gervásio.

## Identidade visual

A página utiliza azul-marinho escuro, azul-marinho claro, branco e bege, com composição editorial, tipografia serifada e capa fotográfica em tela cheia.

## Responsividade

A capa utiliza uma imagem horizontal premium em desktop e uma versão vertical em celular. O conteúdo da primeira dobra permanece legível sobre a foto, com gradiente de contraste e área segura para textos.

## Desenvolvimento

Projeto estático composto por `index.html` e assets locais na pasta `assets/`. Para visualizar localmente:

```bash
python3 -m http.server 4173
```

Depois, acesse `http://localhost:4173`.

## Observação

Informações profissionais, valores, convênios, telefones e agenda devem ser revisados pelo consultório antes da publicação definitiva.
